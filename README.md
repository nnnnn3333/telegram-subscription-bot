# Бот подписки. Первая версия

Оплата производится по штатной платной ссылке канала в Telegram Stars. Telegram управляет продлением и доступом. Реальное нажатие оплаты тратит Stars. Тестовую оплату эта версия не имитирует.

1. Создайте репозиторий GitHub. Загрузите main.py, requirements.txt, README.md и .gitignore в корень репозитория.
2. На Bothost создайте проект Python, укажите ссылку на репозиторий и ветку main. Главный файл main.py.
2. Задайте секрет BOT_TOKEN и запустите бота. Отправьте ему /id.
3. Число из ответа укажите в переменной OWNER_CHAT_ID. Перезапустите бота.
4. Опубликуйте любое сообщение в своём тестовом приватном канале. Перешлите его боту со своего аккаунта. Пересылка должна сохранять источник канала.
5. Бот проверит права и подключит канал. Отправьте /start.
6. PRICE_STARS задаёт цену, по умолчанию 100 Stars за 30 дней.

Подключите постоянный диск Bothost и задайте DATA_DIR с путём его каталога. База хранит подключённый канал и созданные платные ссылки. Для просмотра платежей используйте настройки канала в Telegram. Команда /admin показывает подключение владельцу.

Изменение PRICE_STARS создаёт новую ссылку для будущих покупок, старые подписки сохраняют свои условия. Перед реальными продажами заполните описание предложения и контакт поддержки в main.py. Для портфолио используйте отдельный тестовый канал.

Это первая версия на штатных платных ссылках Telegram. Собственный список подписчиков, возвраты из бота и отдельная демонстрация без оплаты требуют дальнейшей разработки.
